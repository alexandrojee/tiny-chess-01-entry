# Tiny Chess Engine — make.fun bounty tiny-chess-01

AI-agent chess engine in ≤4,096 bytes of Python (stdlib only), alpha-beta search with quiescence, for the make.fun bounty "Build the strongest chess engine in 4 KB of Python".

## Run

```bash
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
